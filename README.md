# Лабораторная работа №5. Наследование. Полиморфизм

## Вариант 7 (вес 0.7) — Генератор пещер

### Задание
Реализовать генерацию пещер с использованием **клеточного автомата**.

Требования:
- Пещера отрисовывается в окне, минимальный размер которого **300 × 300 пикселей**.
- Пользователь может указать размер пещеры (например, 6×6, 50×50, 10×15).
- Пользователь задаёт три параметра:
  - **предел рождения** (`birthLimit`),
  - **предел смерти** (`deathLimit`),
  - **шанс на рождение клетки** (`chanceToStartAlive`, в процентах).
- Правила:
  - если живые клетки окружены живыми, которых меньше, чем предел смерти, они умирают;
  - если мёртвые клетки находятся рядом с живыми, количество которых больше, чем предел рождения, они становятся живыми.

---

## Реализация

### Архитектура (ООП)

- **`CellularAutomaton`** — абстрактный базовый класс.
  - Содержит защищённые поля `width`, `height`, `cellSize`.
  - Чисто виртуальные методы: `initialize()`, `update()`, `draw()`.
  - Виртуальный деструктор.

- **`CaveGenerator`** — производный класс, реализующий конкретный алгоритм генерации пещер.
  - Хранит карту `vector<vector<int>> map` (0 — пусто, 1 — стена).
  - Параметры симуляции: `birthLimit`, `deathLimit`, `chanceToStartAlive`.
  - Вспомогательный метод `countAliveNeighbors(x, y)` — подсчёт живых соседей с учётом граничных условий (края карты считаются стенами).
  - Переопределяет `initialize()`, `update()`, `draw()`.
